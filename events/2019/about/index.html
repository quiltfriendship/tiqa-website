About the Event

關於 2019 友好拼布手作節

2019 友好拼布手作節為台灣國際拼布友好會舉辦之展覽活動， 透過展覽、課程及相關交流，提供拼布及手作愛好者展示作品、 學習交流與分享創意的活動平台。
